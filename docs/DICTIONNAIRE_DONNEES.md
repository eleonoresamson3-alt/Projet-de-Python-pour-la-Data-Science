# Dictionnaire des données livrées

Généré hors ligne par `python -m src.dictionnaire` à partir des colonnes réellement présentes dans `data/processed/`. Le CSV associé fournit une ligne par table et variable, le type stocké, les valeurs manquantes, l'unité, la source, le champ brut et la formule ou définition.

Les codes sont des identifiants, jamais des quantités. Les valeurs manquantes restent distinctes des zéros. Les comptages de gares ne sont pas des voyages uniques ; les modes collectifs INSEE ne désignent pas exclusivement le train. Les projections Omphale et scénarios ne sont pas des observations. Les variables brutes conservées sans usage analytique sont signalées ; les réserves d'unité restent explicites.

## Sources et règles de lecture

Les sources détaillées, URL, empreintes et périmètres sont documentés dans `notes_demographie.md`, `notes_climat.md`, `notes_aviation.md`, `notes_contexte_lgv.md` et le document de méthodologie. Les identifiants de pages INSEE entre parenthèses permettent de retrouver la publication exacte. Les notices DGAC archivées définissent les champs PAP/LSN/EMI.

Les effectifs INSEE de logement et mobilité peuvent être pondérés et non entiers. Les parts sont des ratios d'effectifs ; agréger des parts communales par simple moyenne ne donne pas une part régionale. Les indicateurs de croissance exigent une base strictement positive. Les divergences intersources restent visibles et neutralisent les ratios concernés selon le code de préparation.

Une colonne signalée «à vérifier» ne doit pas être utilisée sans compléter sa définition. Le dictionnaire n'invente aucune unité lorsque la notice ne la précise pas ; c'est notamment le cas de l'unité de distance PAP et de l'échelle TKT, inutilisées dans l'analyse principale.
